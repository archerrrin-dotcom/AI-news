# AI NEWS

中文 AI 新闻简报静态页：每条资讯按时间、背景、内容与来源整理，优先链接一手发布渠道。

## 信息源建议

- 一手：OpenAI、Anthropic、Google AI、Meta AI、Qwen、百度智能云、腾讯混元的官方新闻/博客。
- 政策：工信部、国家网信办、国务院及相关部委网站。
- 补充核验：MIT Technology Review、Reuters、AP、Financial Times、36氪、机器之心。
- 线索发现：Hugging Face、GitHub Trending、X/微博官方账号；线索须回溯至一手来源或至少两家独立权威媒体。

## 发布

提交至 `main` 后，GitHub Actions 将自动发布到 GitHub Pages。
